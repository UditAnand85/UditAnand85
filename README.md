## 🚀 Featured Projects

### RecruitAI — AI-Powered Recruitment Platform
<sub>June 2026 – July 2026</sub>

An end-to-end recruitment platform built to take a hiring team from "resume received" to "candidate shortlisted" with minimal manual work. Incoming resumes are parsed and scored against a role's requirements, candidates are evaluated through automated assessments and video review, and the system handles all the routine back-and-forth — status updates, interview invites, and rejection notices — without a recruiter having to send them by hand. The platform runs as two cooperating services rather than one monolith: an Express.js API that handles auth, candidate data and the recruiter-facing workflow, and a FastAPI service that owns the AI logic — resume parsing, scoring, and agentic evaluation pipelines built with LangGraph and LangChain. Long-running work like parsing a batch of resumes or generating candidate scores is pushed onto Redis-backed BullMQ queues so the API stays responsive under load, and resumes and supporting files are stored on S3.

### NanoLink — Full-Stack URL Shortener
<sub>May 2026 – June 2026</sub>

A TinyURL-style link management platform built to explore clean backend design end to end rather than any single flashy feature. Users can generate short, unique links from long URLs, and every link redirects instantly while its clicks are tracked in the background for basic usage insight. The backend is built as a proper REST API on Express.js, with the short-code generation logic designed to avoid collisions at scale, and Supabase handling persistent storage for links and click data behind a schema built for fast lookups. The React frontend gives users a simple dashboard to create, view and manage their shortened links.

**What it demonstrates:** RESTful API design and routing with Express.js, collision-resistant short-code generation, instant redirection with click tracking, and a database schema built for fast reads on a scalable backend.

### EmailSenseAI — ML-Based Email Classification
<sub>November 2025 – December 2025</sub>

A machine learning system that reads incoming email content and automatically sorts it into predefined categories, built to understand the full pipeline from raw text to a usable prediction rather than just training a model in a notebook. Emails are cleaned and preprocessed before being converted into TF-IDF feature vectors, which are then fed into the classification model for inference. The backend is served through FastAPI with the classification logic built on Flask, and a responsive web interface lets a user submit an email and see the predicted category and confidence returned in real time — closing the loop from raw input to interactive result.

### AI-Based FAQ Chatbot — Academic Project
<sub>January 2025 – April 2025</sub>

A chatbot built to solve a practical, recurring problem — handling repetitive FAQ-style questions without a human reading each one. Rather than hardcoding responses, the chatbot pulls relevant context from a Supabase-backed knowledge base and passes it to the Gemini API to generate a natural, context-aware answer. A wrapper API sits between the database and the model, structuring the query, retrieving the right context, and formatting the model's response before it reaches the user — the same request/retrieve/generate pattern that underlies most practical RAG-style systems.

<img src="https://img.shields.io/badge/Gemini%20API-4285F4?style=flat-square&logo=googlegemini&logoColor=white" alt="Gemini API" /> <img src="https://img.shields.io/badge/Supabase-3FCF8E?style=flat-square&logo=supabase&logoColor=white" alt="Supabase" /> <img src="https://img.shields.io/badge/REST%20API-005571?style=flat-square" alt="REST API" />

**What it demonstrates:** integrating an LLM with a structured knowledge base, designing a wrapper API to connect a database and a model cleanly, and building a basic retrieval-then-generate pattern for grounded responses.
